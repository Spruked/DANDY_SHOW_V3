The Pointer System

Precision Targeting for AI Navigation.

ORB Weaver builds the world's only automated pointer intelligence layer for websites — making AI interaction exact.

What the Pointer System Collects
  • Element bounding-box and screen-position collection
  • Pointer-target extraction from every interactive element
  • Pointer-anchor generation and pointer-manifest generation
  • Pointer plot-map generation for full visual targeting
  • Pointer-target alias generation (multiple names per target)
  • Target-to-route, target-to-section, and target-to-control mapping
  • Scroll-target and viewport-target mapping
  • Fixed and sticky element detection
  • Overlay, z-order, and depth relationship detection
  • DOM anchor collection and ARIA-label binding
What This Enables for AI Agents
  • Zero-guess interaction — AI clicks exactly the right element every time
  • Separate mobile and desktop pointer maps for responsive sites
  • Alias resolution — AI understands login button, sign in, and account access as one target
  • Broken, missing, duplicate, and ambiguous target detection before deployment
  • Pointer-map refresh when site changes
  • Stage-aware targeting — AI knows which pointer belongs to which workflow stage
