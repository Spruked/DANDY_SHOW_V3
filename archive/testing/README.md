# Testing Archive

This folder contains archived testing assets and test-run outputs moved out of active runtime paths.

## Layout
- `results/episodes/`: probe/test episode artifacts
- `results/drafts/`: draft/job records used by probes/tests
- `results/logs/`: runtime test logs
- `tests/`: reserved for archived test source trees when present

See `results/RESULTS_INDEX.md` for the current archived set.
